# laravel-api+frontend

One repository containing **two separate apps**:

```
.
├── .git
├── frontend/   # React (Vite) frontend app  -> http://localhost:3000
└── laravel/    # Laravel REST API backend    -> http://localhost:8000/api
```

Each app has its own README with setup and run instructions:
- [`frontend/README.md`](frontend/README.md)
- [`laravel/README.md`](laravel/README.md)
